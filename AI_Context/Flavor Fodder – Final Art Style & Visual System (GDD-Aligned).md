# **2\. Core Visual Philosophy (VERY IMPORTANT)**

### **Rule \#1: UI \> World**

“Gameplay mostly takes place in the HUD”

This changes everything.

### **Implication:**

* World \= context only  
* UI \= gameplay  
* Characters \= emotional layer

---

# **3\. Camera & World Style**

### **Camera**

* Fixed  
* Slight angle (\~45°)  
* Wide visibility of all stations

### **World Style**

* Clean, minimal, almost schematic  
* Inspired by:  
  * **Hotline Miami (layout clarity)**  
  * Management sims

### **Walls**

* Interior \= blacked out  
* Exterior \= visible

### **Key Rule**

The world is NOT the focus — it’s a **map of decision nodes**

---

# **4\. UI-First Art Direction**

## **4.1 UI \= Primary Visual Layer**

The UI is where:

* Decisions happen  
* Stats are shown  
* Story unfolds

### **Design Style**

* Clean, modular panels  
* Fast appearing/disappearing UI  
* Minimal clutter  
* High contrast

---

## **4.2 HUD Elements (from GDD)**

Must visually prioritize:

* Power Level (MOST IMPORTANT)  
* Skill Level  
* Skill Points  
* Time  
* Station Effectiveness (multiple)

### **Hierarchy Rule**

1. Power  
2. Time pressure  
3. Decisions  
4. Stats

---

## **4.3 UI Behavior**

* Snaps in/out quickly  
* No slow transitions  
* Responsive to taps (mobile-first)

---

  * Hair

# **8\. Color System (Refined for Gameplay)**

## **Primary 5-Color Palette**

1. **Pressure Red** – `#7A0000`  
    → Power struggle, danger, loss  
2. **Work Orange** – `#E07A2F`  
    → Base environment, energy  
3. **Reward Gold** – `#F2C94C`  
    → Progress, upgrades, success  
4. **System Black** – `#121212`  
    → UI base, background, contrast  
5. **UI White** – `#FAFAFA`  
    → Text, clarity

---

## **System Feedback Colors (Gameplay Only)**

* Green → success  
* Blue → info  
* Flash Red → failure

---

## **Color Rule**

Color communicates SYSTEM STATE, not just style
